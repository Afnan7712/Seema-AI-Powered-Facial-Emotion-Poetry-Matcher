# Seema-AI-Powered-Facial-Emotion-Poetry-Matcher
Seema (سِيماء) is an interactive web application that bridges Computer Vision and Classical Arabic Literature. By analyzing real-time facial expressions from user photos, the application identifies the dominant emotional state and dynamically matches it with curated, culturally rich Arabic poetry verses.
Key Features:
Real-time Emotion Recognition: Leverages DeepFace and OpenCV to detect and analyze facial landmarks and expressions.
Cultural Literature Integration: Maps detected emotional states (e.g., happiness, sadness, surprise, composure) to a tailored collection of classical Arabic poetry.
Custom UI/UX Design: Built with Streamlit, custom HTML/CSS, and embedded SVG patterns to deliver a cohesive, aesthetic Arabic right-to-left (RTL) interface.
Robust Fallback Logic: Implemented custom emotion-score routing to handle edge cases and overlapping expressions smoothly.
Tech Stack:
Language: Python 3.10+
Framework: Streamlit
Computer Vision & AI: OpenCV, DeepFace
Styling: HTML5, CSS3, Inline SVGs
